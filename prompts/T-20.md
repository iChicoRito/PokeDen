# Objective
## Pomodoro Timer Page Enhancements: Full-Screen Container Expansion, Physics-Based Pokémon Sprite Dragging, and Background Removal

---

## Role
You are a front-end developer working on a Pomodoro timer web page that also displays Pokémon sprites on the ground. Implement the requested UI and interaction changes carefully, preserve existing behavior unless explicitly changed, and coordinate the work through hierarchical parallel agents as specified.

---

## Description
The task involves three UI and interaction refinements to an existing Pomodoro timer page that shows Pokémon sprites resting on the ground. First, when the user starts the timer, the view currently enters a full-screen state, but the Pomodoro container does not fill the entire screen; it must be expanded to occupy the full available width and height to maximize usable space while the timer is running. Second, the Pokémon sprites must become draggable so the user can grab one, lift it above its ground position, and release it; a sprite dropped above the ground should then fall back down using gravity-based physics to create a more realistic effect. Third, the gradient and any other background color on the Pomodoro container must be removed. The entire effort must be carried out using a hierarchical structure of parallel agents and sub-agents across planning, implementation, and testing, and may only be considered complete after thorough testing passes and all discovered issues are fixed.

---

## Primary Objective
Make the full-screen timer state of the Pomodoro container expand to the full width and height of the screen to maximize the space, while keeping the currently implemented behavior that returns the page to its normal view when the user stops, pauses, or resets the timer.

---

## Secondary Objectives
- Enable the user to drag the Pokémon sprites; because the sprites are positioned on the ground, a sprite that is grabbed, lifted, and released above the ground should fall back down using gravity physics for a realistic effect.
- Remove the gradient and any other background color from the Pomodoro container so it has no background styling.

- **Full-screen layout:** While the timer is running, the Pomodoro container fills the entire viewport width and height; stopping, pausing, or resetting the timer returns the page to its normal layout exactly as currently implemented.
- **Sprite interaction:** The user can grab and drag any Pokémon sprite and drop it above its resting position; a sprite released above the ground falls to the ground with realistic gravity physics.
- **Container styling:** The Pomodoro container no longer shows a gradient or any background color.
- **Quality gate:** Thorough tests covering bugs, failed API calls, broken integrations, edge cases, and regressions are run; all issues found are fixed, and tests are rerun until everything works correctly before the task is marked complete.

## Detailed Breakdown

### Full-Screen Pomodoro Container
When the user starts the timer, the Pomodoro view enters full-screen mode, which works as intended. The problem is that, in that full-screen state, the Pomodoro container does not fill the whole screen. Make the container full width and full height so the available space is maximized while the timer is running. The currently implemented behavior must remain unchanged: if the user stops, pauses, or resets the timer, the page returns to its normal, non-full-screen view.

### Pokémon Sprite Dragging with Gravity Physics
The Pokémon sprites are placed only on the ground, which represents their resting position. The user should be able to grab and drag a sprite and release it at a higher position above the ground. When a sprite is dropped above the ground, it should fall using gravity physics so the interaction feels more realistic; dropping a sprite at or near ground level should behave consistently with its resting state.

### Pomodoro Container Background Removal
In the Pomodoro container, remove the gradient color and any other background color so the container is rendered without background styling.
