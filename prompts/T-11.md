# Objective
## Update the Onboarding Flow and User Portal

---

## Role

You are a software developer responsible for updating the onboarding interface, user portal, and related system functionality. Approach this objective with a focus on interface consistency, usability, and complete removal of obsolete data dependencies.

---

## Description

Improve the onboarding flow by correcting text-field behavior, adding helpful placeholders, standardizing field dimensions, and simplifying the selection interface. Ensure the fields across onboarding steps use consistent default sizing. Remove the preview card container from Step 4. Additionally, eliminate Semester data, fields, and all functionality affected by or dependent on Semester throughout the system.

---

## Primary Objective

Update the onboarding experience and user portal while completely removing Semester-related data, fields, and dependent functionality from the system.

---

## Secondary Objectives

- Use a placeholder rather than a predefined value in the “What’s your name?” text field.
- Add an example placeholder to the “What are you studying?” field.
- Correct the undersized field in Step 3 of 6 so it matches the default text-field size used elsewhere.
- Remove the “Preview:” card container used for selection in Step 4.
- Remove all Semester-related data and functionality from the system.

---

## Success Criteria

- The “What’s your name?” field displays its guidance as a placeholder and does not use a predefined value.
- The “What are you studying?” field includes an example placeholder.
- The field in Step 3 of 6 matches the default size of the other text fields.
- Step 4 no longer displays the “Preview:” card container for selections.
- Semester data, fields, and all affected or dependent functionality are completely removed from the system.

---

## Context & Dependencies

- The changes affect the onboarding pages, user portal, and any system components that currently store, display, process, or depend on Semester information.

---

## Supporting Tasks

### Onboarding Field Updates
- Replace the predefined value in the “What’s your name?” text field with placeholder text.
- Add an example placeholder to the “What are you studying?” field.
- Resize the field in Step 3 of 6 to match the default text-field dimensions used in the other onboarding steps.

### Selection Interface Update
- Remove the “Preview:” card container from the selection interface in Step 4.

### Semester Removal
- Remove Semester data and fields throughout the system.
- Remove or update all functionality affected by the elimination of Semester information.
