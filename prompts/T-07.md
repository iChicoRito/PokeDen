# Objective
## Redesign the Onboarding Companion Selection with Pokémon Profiles

---

## Role

You are a UI developer responsible for planning and implementing the onboarding interface changes while accurately using the provided visual asset.

---

## Description

Redesign the companion-selection interface on the `/onboarding` page to feature the three primary Pokémon characters: Charizard, Blastoise, and Bulbasaur. Replace the existing card-based presentation with character profiles or images extracted from `public\assets\background\pokemon-profiles.aseprite`. Inspect the Aseprite file and its layers to identify and use the detailed artwork for these characters. Limit this companion-selection interface exclusively to the three specified Pokémon.

---

## Primary Objective

Implement a profile-based companion-selection experience on `/onboarding` using the Charizard, Blastoise, and Bulbasaur artwork contained in the provided Aseprite asset.

---

## Secondary Objectives

- Explore the existing onboarding implementation and the structure of the Aseprite asset before finalizing the implementation approach.
- Replace the current companion cards with Pokémon profile imagery while preserving the companion-selection functionality.
- Coordinate planning and implementation through parallel sub-agents.

---

## Success Criteria

- The `/onboarding` companion-selection interface displays Charizard, Blastoise, and Bulbasaur.
- The existing card-based presentation is replaced with profile or character imagery.
- The displayed artwork is sourced from `public\assets\background\pokemon-profiles.aseprite` and identified through its layers.
- No Pokémon other than Charizard, Blastoise, and Bulbasaur appear in this selection interface.
- Parallel sub-agents are used during both planning and implementation.

---

## Constraints

- Use only Charizard, Blastoise, and Bulbasaur in the companion-selection interface.
- Use the detailed character artwork contained in the specified Aseprite file.
- Use parallel sub-agents for exploration during planning.
- Run multiple implementation sub-agents simultaneously.
- Assign implementation sub-agents to different files to prevent editing conflicts.

---

## Context & Dependencies

- The target interface is the companion-selection section of the `/onboarding` page.
- The required source asset is located at `public\assets\background\pokemon-profiles.aseprite`.
- The Aseprite file contains detailed character artwork organized through layers.
- The existing interface currently presents companions as cards.

---

## Supporting Tasks

- [Tag: Parallel] Use sub-agents to inspect the existing `/onboarding` page and identify the files responsible for its companion-selection UI and behavior.
- [Tag: Parallel] Use a separate sub-agent to inspect the Aseprite file, its layers, and the available artwork for Charizard, Blastoise, and Bulbasaur.

- [Tag: Parallel] Assign multiple sub-agents to implement the required UI and asset changes simultaneously.

- Confirm that no unintended Pokémon are included.

## Detailed Breakdown

### Asset Inspection and Preparation

Examine `public\assets\background\pokemon-profiles.aseprite` and its layers to locate the detailed artwork for Charizard, Blastoise, and Bulbasaur. Use only the relevant layers or extracted profile images required for these three characters.

### Companion-Selection Redesign

Replace the current card-based companion choices with profile-oriented Pokémon imagery. The redesigned interface must clearly present Charizard, Blastoise, and Bulbasaur as the only available companions while retaining the underlying selection interaction.

### Parallel Work Coordination

Conduct planning exploration through parallel sub-agents so the existing UI and source asset can be analyzed simultaneously. During implementation, use multiple sub-agents at the same time and divide their responsibilities by file so that no two implementation sub-agents modify the same file.
