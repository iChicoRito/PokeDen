# Objective
## Improve Pomodoro Sprite Visibility and Add Distraction-Free Focus Mode

---

## Role
You are a frontend engineer and multi-agent implementation coordinator. Approach this objective by combining parallel codebase exploration, conflict-free implementation, and thorough regression testing.

## Description
Improve the Pomodoro page by slightly increasing the displayed size of its sprites. Add a distraction-free focus mode that activates when the Pomodoro timer starts, enters fullscreen mode, and hides both the sidebar and navbar. Coordinate planning, implementation, testing, and debugging through parallel agents and sub-agents wherever the work can be divided safely. Continue through verification and issue resolution without interruption until the feature works correctly and no known regressions remain.

## Primary Objective
Create an immersive Pomodoro focus experience by enlarging the sprites and automatically presenting only the Pomodoro interface while the timer is running.

## Secondary Objectives
- Slightly increase the size of the sprites displayed on the Pomodoro page.
- Enter fullscreen mode when the Pomodoro timer starts.
- Hide the sidebar and navbar while the Pomodoro timer is running.
- Restore the appropriate application layout when the focused Pomodoro session ends or exits.
- Use parallel agents and sub-agents throughout planning, implementation, testing, and debugging.

## Success Criteria
- Pomodoro sprites are visibly larger without breaking their layout, proportions, or visual quality.
- Starting the Pomodoro timer requests or activates fullscreen mode.
- The sidebar and navbar are hidden while the timer is running.
- The Pomodoro interface becomes the sole visual focus during an active session.
- The application handles fullscreen rejection, manual fullscreen exit, timer completion, stopping, and resetting without leaving the layout in an inconsistent state.
- Existing Pomodoro controls and behavior continue to work correctly.
- Tests and verification cover bugs, failed API calls, broken integrations, edge cases, and regressions.
- Every discovered issue is fixed, and the relevant checks are rerun successfully before completion.

## Constraints
- Use parallel agents and sub-agents for both planning and implementation.
- During planning, delegate codebase exploration to multiple agents in parallel.
- During implementation, divide independent work across agents using separate files or isolated worktrees to prevent conflicts.
- Do not interrupt the workflow after finalizing the plan; convert the plan into a clear execution goal and proceed directly through implementation and verification.
- Do not mark the task complete until identified issues have been fixed and all relevant tests have been rerun successfully.

## Context & Dependencies
- The changes apply to the existing Pomodoro page and its sprite presentation.
- The focus-mode behavior depends on the Pomodoro timer’s started, stopped, reset, and completed states.
- Fullscreen behavior depends on the browser’s fullscreen capabilities and permission handling.
- Sidebar and navbar visibility must remain synchronized with the active Pomodoro state and fullscreen state.
