# Objective
## Sidebar Companion Dock — Profile Image Source, Alignment, and Level Progress

---

## Role

You are a frontend developer working in the Pokademia PokeDen codebase. Implement a narrow, non-destructive fix to the sidebar Companion dock: correct its profile alignment, switch its avatar source, and add a visible level + progress bar. Preserve all unrelated behavior.

---

## Description

The sidebar Companion dock (`PokeDenSidebar` footer) renders its avatar from Pokemon sprite sheets via a CSS `background-image` div, and the screenshot shows the failure: a blank beige circle with only a tiny blue/black pixel fragment at the bottom-right edge, header text sitting high rather than centered, and no level or progress bar anywhere in the card. The Pomodoro `CompanionDock` already renders correctly from `public/assets/profiles` — the sidebar footer is the only avatar-from-spritesheet left in the app and must be brought into line with it.

---

## Primary Objective

Fix the sidebar Companion dock so the Companion Pokemon is fully visible at a consistent position from `public/assets/profiles`, the header row is vertically aligned, and the user's current (Study) level plus a level progress bar are visible and reflect live XP.

---

## Secondary Objectives

- Replace the sprite-sheet avatar div in the sidebar footer with a `next/image` profile portrait (`entry.image`).

- Keep the `visible=false` PawPrint fallback, the `group-data-[collapsible=icon]:hidden` behavior, and the "View companion" link intact.

## Success Criteria

- Sidebar dock avatar is centered, fully visible, and identifiable as the equipped Companion — not blank, cut off, or showing only a sprite fragment.
- Sidebar dock avatar source is `/assets/profiles/<id>-profile.png` via `COMPANION_CATALOG` / `entry.image`; no `SPRITE_SHEETS`, `sheetUrl`, `backgroundImage`, or `backgroundPosition` remains in `pokeden-sidebar.tsx`.
- The user's current Study Level is visible in the dock (e.g. `Lv {n}` / `Study Level {n}`).
- A level progress bar is rendered in the dock and its value equals `getStudyLevelProgress(studyXp).percentage`; XP-to-next text handles the max-level (`null`) case.
- `npm run check` and `npm run build` pass; no unrelated files regress.
