# Objective
## Parallel Sub-Agent Implementation of the Theme Picker with All Theme Presets

---

## Role

You are a software engineer orchestrating AI sub-agents for a shadcn/ui and Tailwind CSS v4 application. Approach this objective with the mindset of delegating exploration and implementation work across parallel sub-agents while maintaining clean, conflict-free file ownership.

---

## Description

The application must include all of the provided theme presets — the default theme, the "Girly" theme, and the "Coffee Diary" theme — and expose them through a theme picker that lets users choose their preferred appearance. The implementation workflow must use parallel sub-agents: sub-agents are used for exploration during the planning phase, and multiple sub-agents run simultaneously during the implementation phase. To prevent conflicts, each implementation sub-agent must be assigned to edit different files.

---

## Primary Objective

Implement a theme picker that includes all three provided theme presets, using parallel sub-agents for planning exploration and concurrent implementation.

---

## Secondary Objectives

- Include all three provided themes — default, "Girly", and "Coffee Diary" — as selectable presets in the theme picker.
- Use sub-agents for exploration during the planning phase.
- Run multiple sub-agents simultaneously during the implementation phase.
- Assign each implementation sub-agent to edit different files to prevent conflicts.

---

## Success Criteria

- The theme picker exposes the default, "Girly", and "Coffee Diary" presets as user-selectable options.
- Users can choose any of the three themes, and the application's appearance updates to the selected preset.
- Planning exploration is performed by sub-agents in parallel.
- Implementation is executed by multiple sub-agents running concurrently.
- Implementation sub-agents edit distinct files, with no conflicting edits.

---

## Constraints

- Use all three provided theme presets as the available options in the theme picker.
- Parallel sub-agents are mandatory for exploration during the planning phase.
- Multiple sub-agents must run simultaneously during implementation.
- Implementation sub-agents must edit different files to prevent conflicts.

---

## Context & Dependencies

- The themes are shadcn/ui presets distributed through TweakCN, installed with the `npx shadcn@latest add` command and including their provided CSS variable blocks.
- The theming system is built on Tailwind CSS v4, using `@theme inline` blocks and CSS custom properties declared in `:root` and `.dark`, with each preset defining light and dark appearances.

---

## Supporting Tasks

### Planning Phase
- Delegate exploration tasks to sub-agents running in parallel.
- Collect and use the sub-agents' findings to inform the implementation plan.

### Implementation Phase
- Launch multiple implementation sub-agents simultaneously.
- Assign each sub-agent to edit different files to prevent conflicts.
- Integrate the individually edited files into the finished theme picker feature.

---

## Detailed Breakdown

### Included Themes
All three provided presets must be part of the picker.

#### Default Theme
The baseline preset for the entire system, with a warm sand/amber palette, Inter as the sans-serif font, JetBrains Mono as the monospace font, a 0.75rem radius, and subtle downward shadows.

#### Girly Theme
A pink/rose-toned preset with a white background, a rounded 1rem radius, and rose-colored shadows, using Inter as the sans-serif font.

#### Coffee Diary Theme
A warm brown, coffee-inspired preset with serif typography (Libre Baskerville, Lora, and IBM Plex Mono), a small 0.25rem radius, and offset shadows.

### Parallel Sub-Agent Workflow
The planning and implementation phases must be organized around parallel sub-agents.

- Planning: exploration is delegated to sub-agents running in parallel, each investigating a portion of the theming requirements before implementation begins.
- Implementation: multiple sub-agents run simultaneously, each owning a distinct set of files so that concurrent edits do not conflict.
