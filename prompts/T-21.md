# Objective
## Enhanced Pokemon Study App: Sprite Physics, Dialog and Picker Refinements, and Timer Persistence

---

## Description
Implement five connected improvements to a Pokemon-themed study web application that uses a shadcn/ui component template. The work covers animated sprite behavior so that sprites jump randomly at limited height under gravity and resume movement after a maximum idle pause of about one second. It also revises the add-subject dialog at /subjects by removing the Room field and converting its line-variant tab into a segmented control (or the shadcn default tab). The study planner must replace native HTML date and time inputs with shadcn picker components. The pomodoro page must hide sprites outside the container on load or refresh and preserve the running timer across navigation and refresh. Finally, the exam page at /exams/exam-d597ed must use full width like other pages and validate scores that exceed the maximum. All changes are executed through an orchestrator-led parallel-agent workflow and verified by independent review and testing before completion.

## Detailed Breakdown

### Sprite Jump Physics
Sprites must jump at randomized intervals and with randomized but limited height, returning to the ground via gravity simulation rather than a fixed tween. Idle (non-moving) periods should be shortened so a sprite rests for no more than approximately one second before initiating its next movement or jump.

### Subject Add Dialog
The dialog for adding a subject reachable from /subjects currently includes a "Room" input that should be removed entirely. Its tab control uses a line (underline) variant and should be changed to a segmented control style or the default shadcn Tabs component supplied by the project template.

### Study Planner Date and Time Inputs
The /study-planner route currently relies on native or raw HTML date and time fields or pickers. These should be replaced with the shadcn default date picker and time picker components to match the design system.

### Pomodoro Sprite Visibility and Timer State
On every visit or refresh of /pomodoro, sprites currently render as falling from above. They must instead be positioned outside or clipped by the container so they are not visible on entry. Additionally, once the pomodoro timer is started, navigating to other pages or refreshing must not reset or stop it; the elapsed or remaining time and running status must persist.

### Exam Page Width and Score Validation
The /exams/exam-d597ed page content is not full width and should be expanded to match the width of other pages. The score input must handle cases where the user enters a value greater than the maximum score, for example through validation, clamping, or an inline error, so invalid totals are not accepted.
