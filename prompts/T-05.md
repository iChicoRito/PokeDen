# Objective
## Implement Optimized Loading Feedback Across the System

---

## Role
You are a frontend developer focused on user experience and performance. Approach this objective by prioritizing responsive, consistent, and efficient loading states.

---

## Description
Implement loading feedback throughout the entire system so users can clearly identify when content or an action is being processed. Add a skeleton loader to every page for use while page content is loading. Add a loading spinner to every submission button and action control to indicate that the associated process is underway. Ensure both loading mechanisms function reliably and are optimized for performance.

---

## Primary Objective
Implement consistent, reliable, and optimized skeleton loaders and action spinners across the entire system.

---

## Secondary Objectives
- Display a skeleton loader while each page is loading.
- Display a loading spinner whenever a form submission or other user-triggered action is being processed.
- Ensure all loading indicators work correctly and efficiently.

---

## Success Criteria
- Every page displays an appropriate skeleton loader during loading.
- Every submission button and action displays a spinner while its process is running.
- Skeleton loaders and spinners accurately reflect their associated loading states.
- All loading indicators are functional and optimized.
